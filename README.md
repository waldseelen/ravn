# RAVN - Media Downloader

RAVN, YouTube videolarını ve çalma listelerini indirip yönetmeyi kolaylaştıran bir masaüstü uygulamasıdır. Proje kök dizininde kapsamlı teknik dokümantasyon ve geliştirme yol haritası bulunur (`RAVN_DOKUMENTASYON.md`, `ROADMAP.md`).

Kullanım ve build adımları için dokümantasyona bakın.
