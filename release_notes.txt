# RAVN v1.2.0 - Faster Playlists, Crash Reports, and Open-Source Governance

This release focuses on a concrete performance fix users could feel, plus the groundwork for a
more trustworthy, maintainable open-source project: governance docs, security scanning, opt-in
crash reporting, an in-app update check, and a first-pass Windows installer.

## 🚀 Key Improvements & Features

* **Faster, less "laggy" playlist previews:** Detail resolution (size, quality, resolution per
  video) now runs on a parallel worker pool instead of one video at a time, and every row shows an
  instant size estimate the moment the list loads instead of rendering blank while it waits.
* **Opt-in local crash reporting:** If RAVN crashes, a clear, timestamped crash report is now
  written next to your logs so it's easy to attach to a bug report. Fully offline — no data ever
  leaves your machine, and you can turn it off entirely in Settings.
* **In-app update check:** A "Check for Updates" button in Settings tells you whether a newer
  RAVN release is available, without needing to check GitHub manually.
* **Security scanning and SBOM:** Every push is now scanned with CodeQL and `pip-audit`, and each
  release ships a Software Bill of Materials (SBOM) alongside the checksum file.
* **Open-source governance:** Added a security policy, contributing guide, code of conduct, and
  issue/PR templates for anyone who wants to report a bug or contribute.

## 🐛 Fixes

* The update checker previously misreported every outcome as "check failed" due to an internal
  bool/None mix-up — it now correctly reports "up to date" or "update available: vX.Y.Z".

## 🔧 Installation

RAVN is shipped as a portable executable for Windows.
1. Download `RAVN-windows-x64.zip` from this release.
2. Extract the folder and launch `RAVN.exe`.
3. Verify the download against `RAVN-windows-x64.sha256.txt` if you'd like to confirm integrity.
*Note: Windows SmartScreen may appear on first run depending on the code-signing certificate's
accumulated reputation. Click "More info" then "Run anyway" if the checksum matches.*
