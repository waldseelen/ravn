# RAVN v1.3.0 - Cross-Platform Verification

This release moves RAVN from Windows-first to genuinely cross-platform: the full test suite
now runs on Linux, macOS, and Windows in CI on every push and pull request, and two real
platform-specific bugs found during that work are fixed. Packaged (downloadable) releases
remain Windows-only for now; Linux/macOS packaging is a tracked follow-up (see TASKS.md).

## Key Changes

* RAVN is now maintained as a cross-platform product. `tests.yml` runs the full pytest suite
  on Linux, macOS, and Windows on every push/PR, and the project's docs (README, ARCHITECTURE,
  PROGRESS, AGENTS, CLAUDE.md) have been updated to reflect that.
* Fixed a real bug where `yt-dlp`'s self-update path always downloaded the Windows `yt-dlp.exe`
  release asset regardless of OS, silently leaving a non-executable binary in place on
  Linux/macOS. It now downloads the correct asset per platform and marks it executable on
  POSIX.
* Fixed "open with player" doing nothing on macOS (it fell through to `xdg-open`, which
  doesn't exist there) — now uses `open` on macOS, `xdg-open` on Linux, `os.startfile` on
  Windows.
* `ravn.spec`'s Windows-only literals (hardcoded CRT DLL paths, the `version_info.txt`
  PyInstaller argument) are now gated so a future non-Windows PyInstaller build doesn't
  hard-fail on them.

## Not in This Release

* Packaged Linux (AppImage/tar.gz) or macOS (.app/.dmg) builds — the app itself now runs
  cross-platform, but pre-built downloadable artifacts are still Windows-only.
* A native Linux/macOS backend for the one-click tool installer (currently `winget`-only;
  degrades gracefully to a clean "not available" message on non-Windows rather than crashing).

## Installation

RAVN is shipped as a portable executable for Windows.
1. Download `RAVN-windows-x64.zip` from this release.
2. Extract the folder and launch `RAVN.exe`.
3. Verify the download against `RAVN-windows-x64.sha256.txt` if you'd like to confirm integrity.

Note: Windows SmartScreen may appear on first run depending on the code-signing certificate's
accumulated reputation. Click "More info" then "Run anyway" if the checksum matches.

Running from source works on Linux and macOS today (see DEPENDENCIES.md); there is no
packaged build for those platforms in this release.
